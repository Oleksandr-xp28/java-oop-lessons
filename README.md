# Java Study

My notes, lessons and assignments for learning Java: OOP, Exceptions and Generics.

The code grows from lesson to lesson. It is one small Library project: `Book`, `Member`, `Student`, `Teacher`.

## Folders

- `lessons/` - short lessons
- `assignments/` - practical tasks
- `src/` - Java code of the Library project (state after the lesson on Polymorphism and Abstraction)

## Progress

- [x] OOP: Polymorphism and Abstraction (lesson + assignment OOP. 4)
- [ ] Exceptions
- [ ] Generics

## How to run

Checked with Java 21. Run these commands in the main folder of the project:

```
javac -d out src/*.java
java -cp out Main
```

Expected output:

```
Olga can borrow 10
Anna can borrow 5
```
